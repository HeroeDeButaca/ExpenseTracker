# ExpenseTracker
> 🚧 **Work in Progress** — This application is currently under development.

A desktop application developed with **C# and WPF** for managing and tracking personal expenses.

## Features
- Add, edit, and delete expenses.
- Search and filter expenses.
- Expense categories.
- Multi-language support.
- Responsive interface.
- **MVVM architecture** to separate the UI from the application logic.

## Technologies
- **C#**
- **WPF**
- **.NET**
- **MVVM**
- **XAML**
- **SQLite** for local data storage

## Purpose
This project was created to improve my skills in WPF, MVVM, and desktop application development with C#.
The goal is to build a complete expense management application while learning how to structure a WPF project using the MVVM pattern and work with a local database.
